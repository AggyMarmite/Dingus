## What's new in Dingus 0.3.1

* **Plex removed** – the Plex page, the Home row and the Plex settings are gone, so the app is a little lighter.
  Nothing else changes.

**Install:** download `Dingus-Setup-0.3.1.exe` below and run it – or, if you already have Dingus, it will offer this update itself.
